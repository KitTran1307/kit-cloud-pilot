# Contributing

This repository holds the released versions only: each commit here is one release, with its notes in
[CHANGELOG.md](CHANGELOG.md) and on the [Releases](../../releases) page. Development happens elsewhere, so pull requests
are closed automatically (please do not take it personally).

- **Bugs and ideas:** open an issue. Say what you ran, what you expected and what happened, with your OS, Node and
  Claude Code versions.
- **Security problems:** do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Versions:** [Semantic Versioning](https://semver.org). A release never rewrites an earlier one: a fix ships as a
  new version.
